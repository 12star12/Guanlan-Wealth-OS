# V1 范围

> 范围定义文档。任何新增功能，必须先从「做什么」里移除等量功能。

## 一、做什么

| 模块 | V1 内容 |
|---|---|
| 账户 | 账户增删改、分类（资产/负债/收入/支出）、期初余额 |
| 记账 | 收入、支出、转账、退款、补记 |
| 数据 | 复式记账、余额实时计算、备份/恢复、CSV 导入导出 |
| 成绩单 | **三个核心数字**（生存月数 / 负债率 / 储蓄率）+ 收支结构 + 月度趋势 |
| 创收 | 收入来源分布 + 创收行动记录（含三态） |
| 成长 | 成长证据（时间/标题/类型/证据链接），极轻 |
| AI | 每周财务分析、每季度成长与市场价值评估、每月财报 |
| 陪伴 | 每日一句名言（本地库，有出处） |
| 体验 | 温和反馈、无惩罚机制 |

## 二、不做什么

- ❌ AI 对话 / 聊天助手
- ❌ 创收机会推荐（模型会编造案例，真实性无法保证）
- ❌ 与相似人群对比（比较是焦虑之源）
- ❌ 银行/支付平台直连
- ❌ 票据 OCR
- ❌ 预算管理
- ❌ 投资组合追踪
- ❌ 移动端
- ❌ 多用户 / 登录 / 云同步
- ❌ 连续打卡天数（断更惩罚）

## 三、核心指标

首页只放三个数字，不放仪表盘：

| 指标 | 公式 | 回答的问题 |
|---|---|---|
| **生存月数** | 可动用流动资产 ÷ 近 3 月支出中位数 | 我没收入能撑多久 |
| 负债率 | 总负债 ÷ 总资产 | 我的杠杆危不危险 |
| 储蓄率 | 净现金流 ÷ 期间流入 | 我在变富还是变穷 |

> 月均支出用**中位数**不用平均数。一次大额支出会把平均数拉爆。

## 四、AI 产物与频率

| 产物 | 频率 | 内容 | 触发 |
|---|---|---|---|
| 财务周报 | 每周 | 本周收支、异常、趋势、1-3 条建议 | 启动时检查 |
| 月度财报 | 每月 | 完整成绩单，渲染为可打印页面 | 启动时检查 |
| 成长与市场价值 | 每季度 | 能力盘点 + 市场区间定位 | 启动时检查 |

全部惰性触发，不用系统定时任务。

## 五、成长与市场价值

### 5.1 为什么拆成两个

「成长」和「市场价值」是两件事，频率不能一样。

**周度估值会制造焦虑**：这周忙考试没学习，估值掉了，用户看到的是"我退步了"。
而成长的本质是单调的——学过的东西不会消失。**任何会下降的指标都在撒谎。**

所以拆开：

| | 成长积累 | 市场价值 |
|---|---|---|
| 频率 | 每周 | 每季度 |
| 性质 | 只增不减 | 区间估算 |
| 回答 | 我在变厚吗 | 我值多少 |
| 输出 | 证据条数、能力项、作品数 | 区间 + 依据 + 变量 |

### 5.2 成长积累（只增不减）

```
你已积累 47 条成长证据 · 12 项能力 · 8 件作品
本周新增：读完《XX》第 3 章、完成数据分析脚本 1 个
```

**这个数字永远在长，不会掉。** 它不评价，只累积。

作用：低谷期可回看。用户三个月没进展、开始自我怀疑时，能翻到"我曾经做成过 47 次"。
这是记录唯一不可替代的价值——统计可以重算，证据只有当时能留下。

### 5.3 市场价值（季度，给区间不给点值）

**不给单一数字。** "你值 12,000 元"是编的——凭什么不是 8,000？

给：

```
你的能力组合：Python / 数据分析 / 内容创作
参考区间：8k – 15k（一线城市，1-3 年经验）

依据：
- 参考基准来自公开招聘信息整理的区间表（本地文件，可自行修改）
- 你的定位：区间中部

影响上探的变量：
- 完整项目经验：目前 2 个 → 3 个以上可到区间上部
- 可展示的作品集：目前 1 件 → 有对外可访问的作品更受认可
- 团队协作经验：暂无记录

说明：这是参考定位，不是市场定价，也不是收入承诺。
```

**实现方式（防幻觉的关键）**：

1. 本地维护 `market_baseline.json`：岗位/技能组合 → 常见薪资区间。**用户可编辑。**
2. 计算用户的能力档案（技能、项目数、作品数）
3. AI 只做「匹配 + 解释 + 列出变量」，输入是基准表 + 档案，**不允许自行编造数字**
4. 输出的每个数字必须能在基准表里找到

**这个设计的额外好处**：它输出的是"下一步该补什么"，而不是"你值多少"。
前者可行动，驱动持续学习；后者只评价，制造焦虑。用户提的两个目标，前者其实靠这个实现。

## 六、每日名言

**本地名言库，离线，有确切出处。AI 不参与生成。**

LLM 会编造出处（"爱因斯坦说：记账是自由的开始"）。一旦出现假引用，产品可信度归零。

```
quote { text, author, source, tags, used_at }
```

`source` 必须具体到书名/篇章/演讲，不能只写人名。

**选择逻辑：按情境匹配，不随机。**

| 用户状态 | 匹配标签 |
|---|---|
| 本周支出偏高 | 节制 |
| 连续三周无创收 | 坚持 |
| 首次创收 | 开始 |
| 储蓄率上升 | 复利 |
| 无特殊状态 | 通用 |

一条名言如果匹配不上任何状态，就不显示——宁缺毋滥。

## 七、验收标准

### 计算正确性（必须 100%）

- [ ] 录入 100 笔随机交易（含转账、负债、退款），净资产与手工验算一致，误差为 0
- [ ] 任一交易的 `Σ entry.amount == 0`
- [ ] 转账不改变净现金流
- [ ] 借款不计入收入
- [ ] 修改/删除历史交易后余额重算正确
- [ ] 关闭重开，数据完全一致

### 指标

- [ ] 生存月数 = 流动资产 ÷ 近 3 月支出中位数
- [ ] 三个核心指标首屏可见，不需滚动

### AI 产物

- [ ] 报告中每个数字都能在 `facts_json` 中精确找到（自动校验，非人工）
- [ ] 周报「值得肯定」部分的输入事实不含负向数据（结构保证，非 prompt 保证）
- [ ] 生存月数 < 3 时，风险部分必须提及且带具体数字
- [ ] 不出现"你太浪费了""又超支了""目标未达成"等表述（关键词自动检测）

### 成长与名言

- [ ] 成长证据数单调不减
- [ ] 市场价值输出为区间，不是点值
- [ ] 每条名言的出处可在公开文献中查到
- [ ] 名言不重复（短期内）

### 数据安全

- [ ] 一键备份单文件，可在另一台机器完整恢复
- [ ] CSV 导出中文不乱码
- [ ] AI 请求中不含账户名、备注原文
