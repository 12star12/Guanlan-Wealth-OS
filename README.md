# 观澜 Guanlan Wealth OS

## 项目简介

观澜（Guanlan Wealth OS）是一款面向个人用户的智能财富管理与成长分析系统。

通过数据分析、金融知识和人工智能技术，帮助用户理解：

- 当前资产状况
- 收支结构
- 财富成长阶段
- 风险情况


## 项目目标

从个人财富管理工具逐步发展为：

- 个人财富操作系统
- 金融教育工具
- 一人公司经营分析平台


## 当前版本

完成个人资产管理、数据分析和可视化功能。
